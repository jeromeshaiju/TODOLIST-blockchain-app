# TDLBCA — To Do List Blockchain Application

A decentralized To-Do List application built by hosting a static, stylized frontend through a Django web backend, interacting directly with a smart contract deployed on the Ethereum Sepolia testnet.

## 🚀 Features
* **Blockchain-Backed State:** Tasks are stored, added, and marked complete directly on the Ethereum Sepolia testnet.
* **Web3 Integration:** Uses `ethers.js` (v6) to communicate with browser-based wallets like MetaMask.
* **Django Delivery:** Leveraging Django to serve structured static assets and manage environment configurations.

## 🛠️ Built With
* **website:** Python / Django (Static website)
* **Frontend:** HTML5, CSS3, JavaScript (Ethers.js, UI layout designed with AI assistance)
* **Smart Contract:** Solidity (Compiled and deployed via Remix IDE)
* **Network:** Ethereum Sepolia Testnet

---

## 🔧 Smart Contract Deployment
The underlying smart contract managing the task lists was compiled and deployed using the **Remix IDE**. 

* **Network:** Sepolia Testnet

If you wish to view the source code or redeploy, the `.sol` file is available within the `/contracts` directory of this repository.
